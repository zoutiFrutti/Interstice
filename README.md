# Interstice · La Faille Noire

Prototype statique V0.1, sans dépendances, sans publicité, sans cookies applicatifs ni outil d'analyse de fréquentation.

## Démarrer

Ouvrir `index.html` dans un navigateur ou lancer `python3 -m http.server 8000`.

## Publication gratuite

GitHub > Settings > Pages > Deploy from a branch > main > /(root).

## Important

Le formulaire prépare un **brouillon local**. Aucune contribution n'est encore enregistrée ni publiée. La prochaine étape nécessitera une base de données, une API, une modération, une protection contre les données personnelles publiées par erreur et des mesures anti-abus. Ne pas diffuser de QR codes avant cela.

## Collaboration

Modifier le code via des branches et des pull requests. Ne jamais publier de secrets ou de données personnelles dans le dépôt.

La licence libre définitive sera proposée à la future assemblée ; un dépôt public ne constitue pas à lui seul une licence libre.
